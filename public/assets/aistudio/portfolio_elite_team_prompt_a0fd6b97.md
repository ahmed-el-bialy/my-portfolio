### ⏰ GitHub Actions Workflow
```yaml
# .github/workflows/sync-data.yml
name: Sync Portfolio Data

on:
  push:
    branches: [main]
  schedule:
    - cron: '0 6 * * *'  # Every day at 6am UTC
  workflow_dispatch:       # Manual trigger

jobs:
  sync:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v4
      - uses: actions/setup-node@v4
        with:
          node-version: '20'
      - name: Fetch GitHub Data
        env:
          GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
        run: node scripts/sync-github.mjs
      - name: Commit updated data
        run: |
          git config --global user.name 'GitHub Actions'
          git config --global user.email 'actions@github.com'
          git add public/github-data.json
          git diff --staged --quiet || git commit -m 'chore: sync github data'
          git push
      - name: Trigger Vercel Deploy
        env:
          VERCEL_DEPLOY_HOOK: ${{ secrets.VERCEL_DEPLOY_HOOK }}
        run: curl -X POST $VERCEL_DEPLOY_HOOK
```

- When Felix challenges something, the team must RESPOND with evidence.
